# Enterprise AI Work 演示路线与范围

2026-11-11，依据用户最新说明：复刻此前公司的项目，以达到可演示、可讲解的程度；当前不需要真实企业数据。本文定义本轮演示范围，原始 PRD 继续作为完整产品蓝图保留。

## 当前验收口径

- 使用虚构项目、模拟台账、模拟文档与演示账号，不要求获取原公司的业务数据。
- 展示的入口有可观察结果；汇总、修订、审核、整改与验收通过真实本地状态流转，不把静态页面截图当作闭环。
- 能说清数据来源、规则统计、分析建议、人工确认和 Workflow 各自负责什么。
- 模拟数据可以用于验证功能，演示分析也可以使用明确标识的规则/预置输出；不声称这些证明真实模型或 RAG 质量。
- 无真实企业数据不等于禁止真实模型。模型接入可作为演示增强，目前 DEMO_RULES 足以演示现有闭环，不以密钥或客户数据为前提。
- 外部企业连接、生产账号体系、生产扩容/压测、完整运营治理不作为本轮阻断项。已有版本、权限、人工确认和防重复写入机制继续保留。

## 当前已能演示

项目空间、台账维护/CSV、固定汇总运行、快照与证据、报告原稿/人工修订、审核发布、独立确认创建整改、负责人处理、退回重提、经理验收、活动记录和 Markdown 导出。

现已增加知识中心、文档文本解析/版本/授权、本地引用问答、项目与成员管理、待办通知、审计和成果中心；应用模板、Workflow/Agent/模型/工具配置、版本发布/回滚、沙箱预览与运行评估也可操作。分析仍为规则，问答为本地关键词检索与原文摘录；尚未实现的扩展见完整需求台账。

## 推荐讲解路线

以下顺序用于讲清产品，不是对系统生成速度或真实业务效率的承诺。

| 环节 | 页面/操作 | 要讲清的产品价值 |
| --- | --- | --- |
| 项目背景 | 打开项目空间和任务台账 | 输入是项目任务事实；所有企业资料均为模拟数据 |
| 发起汇总 | 选择周期、审核人，确认数据缺口 | 固定 Workflow 负责范围、步骤与权限 |
| 查看过程 | 运行详情、规则统计与台账证据 | 完成率/逾期数由代码计算，分析输出不能改数字 |
| 人工审核 | 查看原稿，撤回修订、重提、核对通过并发布 | 人负责最终内容；每次批准绑定具体正文版本 |
| 独立确认动作 | 从已发布报告选择风险，补负责人/日期/验收标准 | 报告通过不等于自动授权执行建议 |
| 处理与验收 | 负责人提交证据，经理退回/通过 | 风险有负责人和最终结果，处理记录连续保存 |
| 回看成果 | 刷新、查看历史和导出报告 | 结果持久、可追踪，演示不只停在生成文本 |
| 模板运营 | 应用模板 → 模板与 Agent → 派生草稿 → 保存 → 沙箱预览 → 发布 | 配置草稿与发布分开；新任务绑定发布版，旧任务保留原版 |
| 运行治理 | 运行评估 → 运行详情；工具连接 → 工具配置 | 展示本地真实运行状态和工具元数据；无模型调用时用量为零，不编造成本 |
| 只读连接 | 数据连接 → 编辑模拟源 → 检查 → 同步 → 用快照汇总 | 字段映射、水位、旧快照保留与真实外部系统接入是不同层次 |
| 自动草稿 | 定时汇总 → 新建计划 → 立即触发一次 → 查看待审报告 | 使用独立执行身份，只自动生成草稿；审核/发布/整改由人操作 |
| 开放分析 | 开放风险分析 → 目标与范围 → 核对计划 → 执行 | 先确认读取范围，再展示事实、原因假设、缺口和验证建议；当前为规则计划演示 |
| 管理多个项目 | 跨项目概览 → 添加另一示例项目 → 对比与下钻 | 统一当前日期口径；历史趋势仅来自已发布报告，不虚构数据点 |
| 问答后续 | 引用问答 → 追问 → 查看引用/父段 → 反馈；知识反馈 → 记录处理 | 同项目上下文重新鉴权，资料维护有后续处理记录 |

使用 `manager` 发起/审核/验收，`owner` 处理整改，`reviewer` 可作为指定审核人；演示密码均为 `EawDemo!2026`。两种业务角色切换是在演示职责区分，不代表连接了企业账号体系。

## 启动与重复演示

默认启动（保留已有演示记录）：

```sh
./start.sh --port 8765
```

若需要重新从干净台账演示，使用一个**尚不存在的新数据库路径**启动独立实例，不删除或覆盖原数据库。例如在本项目根目录：

```sh
./start.sh --port 8766 --db var/demo-session-01.sqlite3
```

首次初始化按当天上海日期生成任务，起点为 10 项、完成 4 项、完成率 40%、未完成逾期 2 项。相同路径再次启动会恢复已有记录，不会清空；跨日后当前逾期数可能变化，这是日期规则的结果。要保持讲解中的数字一致，可以展示已冻结的报告；不要把旧截点报告说成当天实时数据。

## 讲解用语边界

可以说：“这是原项目的本地复刻，用模拟台账演示完整业务流程；当前分析为演示规则。”

不能说：“这个复刻系统已接通原公司数据”“已验证真实 RAG/模型准确率”或“已达到客户生产 SLA”。原项目的历史业务结果和本复刻工程的验证结果分别说明。
