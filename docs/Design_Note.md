# R1 界面说明与视觉评审

北极星：先看清事实，再确认行动。

用户是项目经理、报告审核人和整改负责人，首屏用于识别当前进度、逾期事项及下一步操作。采用 A「事实控制台」：稳定侧栏与可追溯详情，蓝色强调明确提交，橙色标识待处理风险。B「项目简报」更适合低频阅读，C「行动看板」更适合单一对象队列；当前五类页面需要持续导航，因此采用 A。三种独立首屏的静态研究与 480px 并排图位于 `docs/design/`，它们是视觉研究，不连接业务接口。

没有查询外部竞品画面；本轮围绕 PRD 的核对/审核/处理任务做布局。使用系统中文无衬线字体、等宽对象标识、1.7px 描边图标。配色为 #315fd9 主动作、#f6f8fb 工作区底、#e5eaf1 分隔线，风险使用橙色，已验收使用绿色并伴随状态文字。主视觉由真实规则数字和台账构成，纯数据任务不添加装饰图片。

业务表格、状态表单、正文、引用和错误均可操作。待审、撤回修订、退回、发布中、已发布、整改各阶段均从服务端状态呈现；历史版本的审核操作禁用。数据与错误内容使用文本转义，界面不执行用户 Markdown/脚本。演示模式说明服务于用户判断输出可信边界，保留。

实现的三处基本过渡：按钮 150ms 反馈、页面 150ms 淡入/4px 位移、确认弹窗 170ms 淡入/8px 位移。系统减少动态效果偏好会关闭过渡。不以动效宣称运行进度。

完成一轮隔离上下文的独立静态视觉评审，初版 **8/10**，不代表业务验收或最终版再次获分。随后主开发者自检修正：

- 压缩项目摘要，1366×768 下完整呈现两项逾期事项；删除重复项目口号与重复新建按钮。
- 合并报告正文中的重复标题/统计，将风险事实提前；保留当前版本、修订原因和 hash 绑定信息。
- 提升已验收终态的可见性；活动倒序展示，最终验收结论首先出现。
- 处理证据在左侧保留完整文本，活动中的历史证据默认折叠，避免重复占用阅读空间。
- 去除业务页英语大写眉标与不可操作的下拉符号。

截图由 ego-browser 获取并实际查看，没有自动视觉 lint 报告，未使用其结论代替看图。静态评审未评估动效。证据位置：`docs/evidence/01-overview.png`、`05-report-published.png`、`04-accepted.png`；审核确认与冲突输入保留见 `03-action-confirmation.png`、`06-conflict-input-preserved.png`。

默认目标为 PC 1366×768；附加检查窄屏时的布局与表格横向滚动。生产跨浏览器、读屏工具、全套 WCAG 对比度与动效录屏尚未验收。

## 2026-11-11：工作区导航分级与位置保持

沿用现有事实控制台风格，局部修改导航与项目选择框。目标是先显示日常任务，按需展开其余能力，并让选中位置明确、连续。

- 一级分组：日常协作、项目与资料、分析与自动化、管理与运营。默认只展开日常协作的六个入口，其余按需展开。各组独立折叠，不自动关闭其他分组；业务权限仍决定可见入口。
- 常驻导航：页面切换和后台状态更新仅替换正文、更新导航选中状态和徽标，避免重建侧栏。展开偏好按账号/项目保留，滚动位置在当前浏览会话中恢复；进入资料设置、片段权限、编排详情等子页面时高亮对应入口。
- 选中状态：深蓝底白字（#2448ad），悬停进一步加深，配套焦点轮廓。项目选择框加“当前项目”标签，并固定正常高度，防止长菜单挤压。
- 动效：使用既有 150ms 色彩反馈和页面过渡，折叠箭头 150ms 旋转；列表展开即时完成，避免高度动画造成导航漂移。减少动态效果的系统偏好继续生效。
- 局部自检，未新增独立评审或评分。未删业务说明，导航整理为分组，功能入口均保留。没有运行严格测试集。

实际浏览器检查（1366×768）：展开全部分组后，依次切换审计记录和运行评估，导航/标签 DOM 均保持同一节点；两次切换滚动位置均为 885.5px，点击项纵坐标无变化；刷新恢复相同滚动位置与四组展开状态。前端语法检查通过。默认分级、展开状态截图均已实际查看。
